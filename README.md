# StrideAI extensions

Public home for the [StrideAI](https://aistride.dev) Azure DevOps extensions: bug reports, feature requests and questions, and the planned open-source release of the community edition (MIT, see the [roadmap](https://aistride.dev/#/roadmap)).

- **Documentation:** https://aistride.dev/docs/
- **Report a bug / request a feature / ask a question:** [open an issue](https://github.com/strideaidev/extensions/issues/new/choose) — issues are public, so other teams find the answers too.
- **Private requests** (billing, activation, organization keys, anything with names or data): use the [support page](https://aistride.dev/#/support). It files your request privately.
- **Security vulnerabilities:** use [private vulnerability reporting](https://github.com/strideaidev/extensions/security/advisories/new) or e-mail legal@aistride.dev. Never post a vulnerability in a public issue. See [SECURITY.md](SECURITY.md).

## Before you post

Issues are public and stay public. Please do not include organization keys (`sk_org_…`), API keys or tokens, work item or code content from your project, or names and e-mail addresses of colleagues. Screenshots are welcome when nothing confidential is visible. Maintainers edit or delete issues that contain such data.

## What belongs here

| Repository | Purpose |
|---|---|
| `strideaidev/extensions` (this one) | Issues for the StrideAI Assistant and the companion extensions (Test Case Creator, Work Item Improver, Work Item Analyzer, PR Description, Release Notes, Estimation, Engineering Excellence); source code of the community edition once published |
| [aistride.dev](https://aistride.dev) | Product site, pricing, legal documents, documentation |

Response times: we triage new issues within two business days.
